## What I'm working on

### Hubzada — multi-tenant SaaS in production

A marketing platform where each tenant manages its own content, assets and team, with complete data isolation.

- Multi-tenant architecture with data isolation enforced by PostgreSQL **Row-Level Security**
- Authentication with **NextAuth**, billing with **Mercado Pago**, push notifications via Web Push
- **LGPD** compliance: consent tracking, data export and deletion, audit trail
- **654 commits** over 8 months, CI/CD with **GitHub Actions**, deploy on VPS with **Caddy + PM2**
- Automated tests with **Vitest** and **Playwright**

**Live:** https://hubzada.com

> **About the source code:** the Hubzada repository is private. It is a commercial SaaS in production and contains customer data and business logic. Architecture samples, module walkthroughs and design decisions are available on request — just reach out.
